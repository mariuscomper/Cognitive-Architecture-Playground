# 🎓 Stoicism Presentation - Quick Start Guide

## Start in 30 Seconds

```bash
# 1. Navigate to the directory
cd /Users/mariuscomper/conductor/workspaces/conductor-playground/trenton

# 2. Start the server (automatically opens in browser)
python3 server.py
```

That's it! Your presentation is now running at http://localhost:8000

## Navigation Cheat Sheet

### Keyboard Shortcuts
- **→ or Space** - Next slide
- **← or Page Up** - Previous slide
- **Esc** - Overview mode (see all slides)
- **F** - Fullscreen
- **A** - Auto-play (5 seconds per slide)
- **Home** - First slide
- **End** - Last slide

### Mouse/Touch
- Click arrows on sides to navigate
- Swipe left/right on mobile
- Click "Overview" to see all slides
- Click any thumbnail in overview to jump to that slide

## Presenting Tips

1. Press **F** for fullscreen before starting
2. Use **Esc** to show overview on a second monitor
3. Press **A** for auto-play mode if needed
4. Use **arrow keys** for smooth navigation

## Troubleshooting

**Page won't load?**
- Make sure you're using a local server (run server.py)
- Don't open index.html directly in browser

**Content missing?**
- Check that presentation_data.json is in the same folder
- Try hard refresh (Ctrl+Shift+R or Cmd+Shift+R)

## Customization

Edit `presentation_data.json` to change content.
Edit CSS in `index.html` to change colors/styling.
Edit `app.js` to modify behavior.
