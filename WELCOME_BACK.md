## 🛠️ Easy to Customize

Want to change something?

### Change Content
Edit `presentation_data.json`:
```json
{
  "slides": [
    {
      "title": "Your New Title",
      "content": "Your new content"
    }
  ]
}
```

### Change Colors
Edit CSS variables in `index.html`:
```css
:root {
    --primary: #C49A6C;    /* Change this */
    --secondary: #5C6D67;  /* And this */
}
```

### Change Auto-play Speed
Edit `app.js`:
```javascript
this.autoPlayDelay = 5000; // Change to any milliseconds
```
