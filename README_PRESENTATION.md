## 🎨 Customization

### Change Content
```json
// Edit: presentation_data.json
{
  "slides": [
    {
      "title": "Your Title",
      "content": "Your content"
    }
  ]
}
```

### Change Colors
```css
/* Edit: index.html */
:root {
    --primary: #C49A6C;
    --secondary: #5C6D67;
}
```
