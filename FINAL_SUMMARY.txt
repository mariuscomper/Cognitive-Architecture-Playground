HOW TO USE
================================================================================

QUICK START:
   1. Server is already running at: http://localhost:8000
   2. Just open that URL in your browser
   3. You're ready to present!

IF SERVER STOPPED:
   ./RUN_PRESENTATION.sh
   OR
   python3 server.py

KEYBOARD SHORTCUTS:
   → or Space     = Next slide
   ←              = Previous slide
   Esc            = Overview mode (see all slides)
   F              = Fullscreen mode
   A              = Auto-play mode
   Home           = First slide
   End            = Last slide
